# Stage 1: trying it on your iPhone and iPad

## One-time setup (2 minutes)

1. On GitHub, open the repo → **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Open the **Actions** tab. If the "Deploy to GitHub Pages" run failed earlier because Pages was off, open it and press **Re-run all jobs**.
4. When it's green, the game is at **https://bodrid.github.io/Iron-and-gold/** (capital I — GitHub uses the repo's exact name).

## On the iPhone 17 Pro

1. Open the address in **Safari**, tap **Share → Add to Home Screen → Add**.
2. Launch it from the Home Screen icon (not from Safari).
3. Check, and note anything that's off:
   - [ ] It fills the screen; nothing is hidden behind the Dynamic Island with the phone turned **either** way.
   - [ ] Holding the phone upright shows "Turn your phone sideways".
   - [ ] Pinch-zooming and dragging the map feel smooth, zoomed all the way out over the whole world too.
   - [ ] New game → pick a country → tap one of your states → **Build here** → build a farm.
   - [ ] Tap unclaimed land next to you (for example as the USA, Kansas) → **Attack** → speed 3 → your borders grow.
   - [ ] Ten minutes at speed 3: the phone doesn't get hot and the game keeps up.
   - [ ] Swipe home, wait, reopen: **Continue** puts you back where you were.
   - [ ] Turn on airplane mode, launch from the icon: it still starts.

## On the iPad Air

Same steps. Also check:
- [ ] Opening a tab docks the panel on the right; the map stays visible.
- [ ] Split View (with another app beside it) switches to the phone-style pull-up panel and still works.
- [ ] Portrait works too.

Anything wrong? Tell Claude what you saw (a screenshot helps).
